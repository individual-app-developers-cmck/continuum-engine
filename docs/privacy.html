Privacy Policy for Continuum Engine

Effective Date: November 28, 2026 | Application: Continuum Engine

This Privacy Policy describes how Continuum Engine ("the Application", developed and operated by Continuum Engine) accesses, uses, stores, protects, and deletes user data, including Google user data accessed through Google Workspace APIs and the Google Workspace Model Context Protocol (MCP).

1. Google User Data We Access

Google Drive integration is strictly optional. When a user explicitly authorizes the Application via Google OAuth 2.0 using the narrow https://www.googleapis.com/auth/drive.file scope, the Application accesses only:

  • Metadata and content revisions of the specific Google Drive files explicitly created by the Application or explicitly designated by the user (by File ID).
  • The Application does not access, read, index, or list any other files in the user's Google Drive.

2. How We Use Google User Data

Google user data is used exclusively to provide the user-facing Bring Your Own Document (BYOD) synchronization feature—specifically, writing AI inference results and telemetry logs directly to the user's own designated Google Drive file at the user's explicit request. We do not use Google user data for targeted advertising, personalized advertising, creditworthiness, lending, data brokering, or building external databases.

3. Prohibition on AI/ML Model Training

Explicit AI/ML Disclosure: Continuum Engine affirms that Google Workspace APIs and any Google user data obtained through them are never used to develop, improve, or train generalized or non-personalized artificial intelligence (AI) and/or machine learning (ML) models.

4. Data Sharing, Transfer, and Disclosure

We do not sell, rent, transfer, or disclose Google user data to any third parties, advertisers, data brokers, or information resellers for any purpose.

5. Data Protection Mechanisms

We implement strict technical and architectural security safeguards to protect the confidentiality and integrity of sensitive data:

  • Encryption in Transit: All communications with Google OAuth 2.0 endpoints, Google Workspace MCP endpoints, and Continuum Engine APIs are encrypted via industry-standard HTTPS/TLS.
  • Client-Side Zero-Trust Architecture: OAuth 2.0 access tokens, refresh tokens, and Google Drive file contents are processed strictly locally within the user's own client environment and are never transmitted to, logged on, or stored by Continuum Engine backend servers.
  • Least-Privilege Scope: Access is restricted strictly to the per-file drive.file scope.

6. Data Retention and Deletion

  • Local Tokens & Drive Files: OAuth tokens are stored solely on the user's local machine and remain under the user's sole control. Synced documents reside exclusively in the user's own Google Drive.
  • Ephemeral Server State: When running in Stateless Mode (without Drive sync), no conversation history is retained on Continuum Engine servers. Any minimal session pointers expire and are automatically purged after 7 days.
  • How to Delete Data & Revoke Access: Users may delete local token files and Google Drive documents directly at any time, and may immediately revoke the Application's access via Google Account Permissions. To request deletion of any account or billing records held by us, contact continuum@openvirtualweddingjp.com.

7. Google API Services User Data Policy Compliance

Continuum Engine's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Policy Changes & Contact

If we materially change how Continuum Engine uses Google user data, we will update this page and notify affected users prior to applying the change. For any privacy questions or deletion requests, please contact: continuum@openvirtualweddingjp.com
